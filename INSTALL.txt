AppMixer 0.2.0 — Preview
Apple Silicon (arm64), macOS 14.2 or newer.

Drag AppMixer.app to Applications, then open it. Use its menu-bar slider icon.
The app automatically attempts activation and macOS may request system audio
recording permission. Only approve if you want per-app volume control.

The official 0.2.0 release ZIP is Developer ID signed and Apple notarized,
with its ticket attached. Local builds made by scripts/package.sh are
ad-hoc signed and are not notarized. Check the release notes for status.

Start with built-in speakers. This prototype supports limited Float32 stereo
output layouts. Bluetooth and multichannel devices may not be supported.
Real Chrome/Spotify audio isolation, crash recovery, latency and long-running
playback have NOT yet been validated. No driver or default-output change is
required. Audio is processed locally and is not saved or uploaded.

Choose Stop & Restore to stop processing; Quit exits the app.

Launch at Login is optional and can be enabled from the menu-bar panel.
Check for Updates checks the signed update feed. Automatically Check for
Updates is off by default. Installation requires user confirmation.
Install this Sparkle-enabled version manually once; later verified releases
can be installed through the app. An empty feed means no update is available.
